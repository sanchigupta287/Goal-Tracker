#  Goal Tracker

## About the Project

 Goal Tracker is a simple Python-based application that helps users manage their goals.

The user can add goals, view them, mark them as completed, check overall progress, and delete goals.

The project is created using basic Python concepts from the Python Essentials course.

## Features

- Add a new goal
- View all goals
- Mark a goal as completed
- Show goal progress
- Delete a goal
- Save goals in a text file
- Load saved goals when the program starts
- Basic input validation

## Technologies Used

- Python
- Text file handling
- Python Array
- Object-Oriented Programming

## Project Files

### main.py
Contains the main menu and controls the program.

### goal.py
Contains the `Goal` class and its methods.

### functions.py
Contains the main functions such as adding, viewing, completing, deleting goals and showing progress.

### storage.py
Handles saving and loading goals using `goals.txt`.

### goals.txt
Stores the saved goal information.
